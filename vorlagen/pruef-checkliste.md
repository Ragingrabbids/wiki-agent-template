# Prüf-Checkliste für Wiki-Entwürfe

Getrennter Durchlauf: so prüfen, als stamme die Seite von jemand anderem.

## Quellen
- [ ] Jede Faktaussage hat eine Quellenmarkierung.
- [ ] Jede Quellenangabe wurde im Extrakt nachgeschlagen und gefunden.
- [ ] Alle Zahlenwerte, Einheiten und Sicherheitshinweise stimmen **wörtlich** mit der Quelle überein.
- [ ] Keine Aussage ohne Beleg (sonst entfernen oder unter „Offene Fragen“).

## Struktur
- [ ] Alle Pflicht-Metadaten ausgefüllt; Begriffe nur aus `TAXONOMIE.md`.
- [ ] Parameter als Tabelle.
- [ ] Eine Seite = ein Thema; Überschneidungen mit anderen Seiten verlinkt statt doppelt beschrieben.

## Konsistenz
- [ ] Keine Widersprüche zu bestehenden Seiten in `wiki/` – sonst unter „Offene Fragen“ + `review/`.
- [ ] Widersprüche zwischen Quellen sichtbar gemacht, nicht stillschweigend aufgelöst.

## Lenkung & Klassifizierung
- [ ] Keine Inhalte aus gelenkten Dokumenten kopiert; stattdessen Link in `lenkung_verweise`.
- [ ] Kein Widerspruch zu einem gelenkten Dokument (sonst offene Frage an QMB).
- [ ] Klassifizierung der Seite = höchste Klassifizierung ihrer Quellen.
- [ ] Keine Inhalte aus streng vertraulichen Kundenunterlagen.

## Datenschutz
- [ ] Keine personenbezogenen Daten über das Nötige hinaus (Rollen statt Namen, außer „verantwortlich“).

## Ergebnis
`pruefung: bestanden` oder `pruefung: nachbesserung` + Liste der Mängel in `review/`.
